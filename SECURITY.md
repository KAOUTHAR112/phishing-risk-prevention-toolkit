# Security Policy

## Supported version

Security fixes are maintained for version 2.x of this academic project.

## Reporting a vulnerability

Do not publish sensitive vulnerability details in a public issue. Contact the repository owner privately through the contact method listed on their GitHub profile and include:

- affected file or component;
- reproduction steps;
- expected and actual behavior;
- security impact;
- suggested mitigation, when available.

## Safe-use statement

The application analyzes URL text only. It does not open submitted websites. Do not modify the project to automatically visit untrusted URLs on a personal or production computer without isolation, strict timeouts, and professional sandboxing controls.
