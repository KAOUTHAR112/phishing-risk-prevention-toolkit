# Dataset Notes

`dataset_phishing.csv` was supplied with the original student project. The project documentation identifies it as the **Web Page Phishing Detection Dataset** available on Kaggle.

The training script uses only:

```text
url
status
```

All live model inputs are derived from the raw URL. The other original columns are retained for traceability but are not used by version 2.0.
